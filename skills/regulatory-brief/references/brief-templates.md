# Brief templates

Fill these from the records. Leave a line out when the record has no value for it, or write "not listed in the record" when the user asked for that value.

## Single topic brief

```text
[One or two sentences that answer the question.]

Final rules
1. [Title]
   [Agency] · Final rule · Document [number]
   Published [date] · Effective [date]
   [One sentence from the summary.]
   [federalregister.gov link]

Proposed rules
1. [Title]
   [Agency] · Proposed rule · Document [number]
   Published [date] · Comments close [date]
   [One sentence from the summary.]
   [federalregister.gov link]

Notices
1. [Title] · [Agency] · Document [number] · Published [date]
   [link]

What this covers: [query, agency, type, window]. [N] results were set aside as off topic.
The records are summaries. The regulatory text and the official edition are at each link.
```

## Agency digest

```text
[Agency], documents published since [date]: [counts by type].

Rules: [list as above]
Proposed rules: [list as above]
Notices worth a look: [short list]
Routine notices: [count], for example meeting announcements and information collection requests.
```

## Proposed versus final comparison

```text
| | Proposal | Final rule |
| --- | --- | --- |
| Title | | |
| Document number | | |
| Published | | |
| Comments closed | | n/a |
| Effective | n/a | |
| Link | | |

Basis for treating these as one rulemaking: [same title / the final rule's summary cites the proposal / same docket in the comment link].
What the summaries say changed: [only what the summaries state; otherwise "the summaries do not describe the changes, see the final rule's preamble at the link"].
```

## Wording to keep

- "Proposed rule" and "final rule" in full. Do not shorten either to "rule" alone.
- "Not listed in the record" for a missing date.
- "As published" when describing a rule, since the record does not show later changes.
- "At least 10,000" when the count shows 10000.
